# LAR 0.10.0

Workspace version: `0.10.0`  
Binaries: `lar`, `lar-exec`

Follows [0.9.0](0.9.0.md).

## What’s new

### Dependency resolver
- PubGrub conflict-driven solver (prefers highest matching versions; one version per id)
- Peek candidate metadata from the package index during search; fetch only winners
- Unsatisfiable graphs report a PubGrub derivation tree
- Resolve failures on yanked-only matches report an explicit yank error

### Package sources
- Source order in `sources.toml` is priority (earlier = higher); `lar repo move` reorders
- Resolve/fetch: collect matching versions → highest compatible version → if the same pin is in multiple sources, highest-priority source; never merge contents
- Index embeds dependency metadata in the **signed** pin payload so resolve probes without downloading `.lar` archives (republish existing indexes with `lar repo index` — pin signatures now cover id/version/hash/file/deps, not content_hash alone)
- `lar repo add` trusts the publisher key from `{base}/ed25519.pub` (confirm / `--yes` / `--fingerprint`); `init`/`index`/`publish` write that file
- Removed `fetch_priority` / `lar repo priority` (`first-win` / `last-win`)
- Removed source `--main` / `--policy` flags; install and resolve use the same configured sources

## Install from source

```bash
git clone https://github.com/hus201/lar.git
cd lar
git checkout v0.10.0
cargo build --release -p lar -p lar-exec
```

Place `lar` and `lar-exec` on `PATH` (same directory so sibling resolution works), or set `LAR_EXEC` to the trampoline binary.

## Dist packages

```bash
cargo install cargo-deb cargo-generate-rpm   # once
./packaging/dist.sh
```

Artifacts appear under `dist/`. See [packaging/README.md](../../packaging/README.md).

```bash
# Debian / Ubuntu
sudo dpkg -i dist/lar_0.10.0-1_amd64.deb

# Fedora / RHEL (dnf)
sudo dnf install ./dist/lar-0.10.0-1.x86_64.rpm

# Native tarball
tar -xzf dist/lar-0.10.0-linux-x86_64.tar.gz
sudo install -m 755 lar-0.10.0-linux-x86_64/bin/lar \
  lar-0.10.0-linux-x86_64/bin/lar-exec /usr/local/bin/
```

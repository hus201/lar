# LAR 0.8.0

First public MVP release of [LAR](https://github.com/hus201/lar) (Linux Application Runtime).

Workspace version: `0.8.0`  
Binaries: `lar`, `lar-exec`

## What’s in this release

### Packages and store
- `package.toml` / `.lar` archives with BLAKE3 content hashes
- Side-by-side store (`lar store add` / `list` / `remove`)
- Install pins block removal of packages still required by apps

### Resolve and lockfile
- `lar resolve` with semver requirements (`^`, `~`, comparisons; no bare `*`)
- Highest matching version per id; conflicts without backtracking
- Fetch missing pins from configured package sources
- Writes exact pins to `lar.lock`

### Runtime
- Compose modes: symlink (default), hardlink, copy
- Shared launch environment (`PATH`, `LD_LIBRARY_PATH`, `LAR_RUNTIME`)
- `lar runtime` build / list / inspect / gc
- `lar run` for lockfile-oriented development (not the normal installed-app path)

### Install lifecycle
- `lar install` / `list` / `update` / `rollback` / `uninstall` / `launch`
- Single previous generation for rollback
- Uninstall removes install record, desktop, PATH exports, and runtimes; store packages remain

### Package sources (repos)
- `lar repo` sources + trust store
- Ed25519 signatures over package `content_hash` on fetch
- Signed `advisories.toml` (BLAKE3 `content_hash` + Ed25519 over that string)
- Yank refuse on new fetch; warnings and `lar audit` for elevated findings

### Desktop and PATH
- Freedesktop `.desktop` publish for packages with `[entry]`
- PATH exports via slim `lar-exec` trampoline (`{prefix}/libexec/lar-exec`)
- Collision refusal for non-LAR paths; PATH shadow warnings on install/update/rollback
- Menus / PATH are the normal launch path; `lar launch` is admin/debug

## Out of scope for 0.8.0

- Full backtracking dependency solver
- MIME handlers, portals, D-Bus activation, systemd service metadata
- Mandatory sandboxing (not a LAR goal)
- Automatic SxS store GC (use `lar runtime gc` for runtimes; store cleanup remains manual)
- Atomic activate-then-publish for exports/desktop

## Install from source

```bash
git clone https://github.com/hus201/lar.git
cd lar
git checkout v0.8.0   # when the release tag is published
cargo build --release -p lar -p lar-exec
```

Place `lar` and `lar-exec` on `PATH` (same directory so sibling resolution works), or set `LAR_EXEC` to the trampoline binary.

# LAR 0.9.0

Workspace version: `0.9.0`  
Binaries: `lar`, `lar-exec`

Follows [0.8.0](0.8.0.md) (first public MVP).

## What’s new

### Publisher repo tools
- `lar repo init` — scaffold `packages/` and an empty signed `index.toml`
- `lar repo publish` / `unpublish` — add or remove `.lar` pins and rebuild+sign the index
- `lar repo validate [--pubkey …]` — check layout, content hashes, and (optionally) signatures
- Existing `lar repo index` remains for full rescan / advisory resign

### Guides
- Task-oriented docs under [docs/guides/](../guides/): create a package, publish a source, use a source, install/update apps

## Install from source

```bash
git clone https://github.com/hus201/lar.git
cd lar
git checkout v0.9.0
cargo build --release -p lar -p lar-exec
```

Place `lar` and `lar-exec` on `PATH` (same directory so sibling resolution works), or set `LAR_EXEC` to the trampoline binary.

## Dist packages

```bash
cargo install cargo-deb cargo-generate-rpm   # once
./packaging/dist.sh
```

Artifacts appear under `dist/`. See [packaging/README.md](../../packaging/README.md).

```bash
# Debian / Ubuntu
sudo dpkg -i dist/lar_0.9.0-1_amd64.deb

# Fedora / RHEL (dnf)
sudo dnf install ./dist/lar-0.9.0-1.x86_64.rpm

# Native tarball
tar -xzf dist/lar-0.9.0-linux-x86_64.tar.gz
sudo install -m 755 lar-0.9.0-linux-x86_64/bin/lar \
  lar-0.9.0-linux-x86_64/bin/lar-exec /usr/local/bin/
```
